# Portfolio Website

This repository contains a professional, production-ready portfolio website built with Vite, React, TypeScript, Tailwind CSS, and shadcn-ui.

## Local development

Prerequisites: Node.js (16+), npm or yarn.

Quick start:

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

## Technologies

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui

## Deployment

Deploy this project with your preferred platform (Vercel, Netlify, Cloudflare Pages, etc.). Build with:

```sh
npm run build
```

Then follow the hosting provider's instructions to upload the static output from the `dist` (or equivalent) folder.

- Replace the site metadata in `index.html` with your brand details.
